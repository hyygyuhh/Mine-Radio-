Folia lyric visualizer
======================

Upstream: https://github.com/chthollyphile/folia-major
License: GNU Affero General Public License v3.0 (AGPL-3.0)

Mineradio ships a built full-screen embed at vendor/folia/ (built from
folia-major via `npm run build:mineradio-embed` / scripts/build-folia-embed.ps1).
Current vendor bundle targets Folia Realeco v0.7.26 (tag v0.7.26). The page
loads that static bundle; users do not install Folia separately. Preserve
Folia's copyright notices and provide corresponding source when redistributing
combined builds.

Nebbia (雾笺) stroke medians are generated at embed build time from AnimCJK
(Arphic Public License) into vendor/folia/nebbia-strokes.json and
vendor/folia/licenses/nebbia-strokes/ (COPYING.txt, ARPHICPL.TXT, NOTICE.txt).
If the AnimCJK download fails during build, Nebbia still runs but falls back
to font-skeleton stroke estimates.
