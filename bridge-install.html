Mineradio Bridge 安装说明

网页版搜索、播放与账号同步依赖本机 Bridge 扩展。按下面步骤安装后，回到 mineradio.art 即可继续登录听歌。

Mineradio Bridge Chrome / Edge 扩展 · Cookie 留在本机 · 不上传账号与听歌记录

1下载扩展包（当前版）

正在加载下载链接…

电脑请下载 zip 后解压成文件夹（不要只打开压缩包内部）。iPhone / iPad 若用 Orion 浏览器，可直接安装 zip。

历史版本

一般请用当前版。仅在排查兼容性问题时再装旧版；装完需在扩展管理页移除旧扩展后重新「加载已解压」。

2在 Chrome / Edge 加载

  1. 打开扩展管理页
    地址栏输入 chrome://extensions（Edge 为 edge://extensions）并回车。
  2. 开启开发者模式
    页面右上角打开「开发者模式」开关。
  3. 加载已解压的扩展程序
    点「加载已解压的扩展程序」，选中解压后的文件夹（里面应能看到 manifest.json）。
  4. 固定到工具栏（推荐）
    点浏览器工具栏拼图图标，把 Mineradio Bridge 固定出来，方便点「刷新状态」。

3登录音乐平台并检测

  1. 在浏览器中登录需要的平台： 网易云 / QQ 音乐 / 酷狗
  2. 点扩展图标 → 刷新状态，确认对应平台已显示已登录。
  3. 打开 https://mineradio.art/，在登录面板点「重新检测」。状态变为已连接后即可继续。

4手机（可选）

  1. iPhone / iPad：使用支持扩展的 Orion 浏览器（官网）→ 扩展 → 从文件安装 Bridge 的 zip。
  2. Android 手机 / Pad：系统 Chrome 通常无法加载未上架扩展；可用支持扩展的 狐猴浏览器（官网）安装 Bridge。也可使用电脑浏览器，或 mineradio.cn 客户端。

常见问题

提示「未连接到 Bridge」？

确认扩展已启用且未被浏览器禁用；打开扩展弹窗点「刷新状态」；刷新 mineradio.art 后再点「重新检测」。若刚重装过，需重新「加载已解压的扩展程序」。

加载扩展时报错 / 找不到 manifest？

请选择解压后的根目录，该目录下应直接有 manifest.json。不要选 zip 文件本身，也不要多套一层空文件夹。

平台显示未登录，但官网已经登录？

确认登录的是同一浏览器配置文件；点扩展「刷新状态」。从 Mineradio 点「官网登录」完成登录后回到页面，一般会自动同步；也可手动刷新状态。

图标变成青色拼图？

多为未正确加载图标或旧包占位图。请确认使用最新 v1.4.3 包，移除旧扩展后重新加载解压目录。

Cookie 会上传吗？

不会。登录 Cookie 只在本机给网页版代理接口使用。详见 隐私政策。
