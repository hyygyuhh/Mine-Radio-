Mineradio

隐私政策

适用于 mineradio.art 网页版与 Mineradio Bridge 浏览器扩展 · 最近更新：2026-11-03

一句话：听歌登录用的 Cookie 留在你的浏览器本机；我们不收集账号密码、听歌记录或歌单内容。网页可能使用访问统计了解站点可用性；Bridge 可选匿名心跳只含随机安装 ID 与版本号。

1. 我们是谁

Mineradio（mineradio.art）提供免费网页版在线听歌与可视化体验。客户端下载见 mineradio.cn。联系邮箱：support@mineradio.cn。

2. 网页版处理的数据

  • 本机偏好：播放设置、界面状态等保存在浏览器 localStorage，不上传到我们的服务器。
  • 音乐平台会话：登录态通过本机 Cookie（及 Mineradio Bridge）访问网易云 / QQ 音乐 / 酷狗等平台接口；Cookie 不会发往 mineradio.art 服务器。
  • 静态托管：访问网页时，托管方（如 GitHub Pages / CDN）可能产生常规访问日志（IP、User-Agent、路径），用于可用性与安全，不作听歌画像。

3. 网站访问统计

为了解页面打开情况与基础可用性，网页版可能加载下列第三方分析脚本（与听歌账号、歌单、搜索词无关）：

  • 百度统计（hm.baidu.com）：记录页面浏览量、来源与设备等聚合访问数据，可能使用 Cookie 或类似标识。
  • Microsoft Clarity（clarity.ms）：用于会话回放与热力图类体验分析，可能记录页面交互与设备信息，并使用 Cookie 或本地标识。

你可通过浏览器阻止第三方脚本、清除站点数据，或使用追踪防护功能限制上述能力。若政策或脚本变更，我们会尽量在本页更新说明。

4. Mineradio Bridge 扩展

  • 用途：在本机读取你已在音乐官网登录的 Cookie，代理网页版所需的音乐 API 请求。
  • 权限：cookies、storage、tabs、alarms、declarativeNetRequest 与相关主机权限，仅用于上述代理与媒体 Referer。
  • 退出登录：在网页版退出对应平台时，扩展会清除该平台相关登录 Cookie。
  • 不会：上传你的账号密码、完整 Cookie 内容、听歌历史或搜索关键词到 Mineradio 服务器。

5. 匿名活跃统计（可选）

扩展可能向 https://mineradio.art/bridge/ 发送匿名心跳，仅包含：

  • 随机生成的安装 ID（UUID，与个人身份无关）
  • 扩展版本号
  • UTC 日期（用于日活去重）

公开汇总接口供维护查看，不含 Cookie、账号、曲目或搜索内容。

6. 其他第三方

播放与登录依赖各音乐平台官方服务及其隐私政策。动态壁纸、天气等可选功能可能请求公开第三方 API；详见各功能说明。

7. 你的选择

  • 可不安装 Bridge，仅使用不依赖扩展的功能。
  • 可随时在浏览器中卸载扩展、清除站点数据或退出音乐平台账号。
  • 疑问请邮件 support@mineradio.cn。

8. 政策更新

我们可能不时更新本政策；重大变更会尽量在本页注明日期。继续使用即表示知悉更新后的说明。
